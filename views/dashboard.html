INTEGRATION GUIDE

API documentation

Use your business API key to authenticate requests.

Base URLhttps://your-domain.com/v1

Authentication

Send your API key in the X-API-Key header. Never expose your API key in browser or mobile code.

X-API-Key: zy_test_your_secret_key

Available endpoints

GET/v1/statusCheck API key and workspace status
POST/v1/kycSubmit a customer KYC
GET/v1/kyc/status?email=customer@example.comRetrieve provider KYC status
POST/v1/cardsCreate a card for an approved customer
GET/v1/cardsList cards belonging to your business
GET/v1/cards/:cardIdGet card details
POST/v1/cards/:cardId/fundingFund or withdraw from a card
POST/v1/cards/:cardId/statusFreeze or activate a card

KYC request fields

Provider-required fields include first_name, last_name, id_number, email, phone_number, date_of_birth, dial_code, id_front_image (Base64), address fields, country (three-letter code such as HTI), id_type, occupation, employment_status, account_purpose, annual_salary, expected_monthly_volume and place_of_birth.

Example request

curl -X POST https://your-domain.com/v1/kyc \
